# PassATS AI — Internal Version

PassATS AI is a Streamlit-based internal system that analyzes resumes and calculates ATS compatibility scores.  
It evaluates keywords, skills, and experience to determine how well a resume matches a job description.

---

## Features
- Instant resume analysis
- Accurate ATS score calculation
- Missing keyword detection
- Automatic improvement suggestions
- Fast and clean English interface

---

## How It Works
1. Upload the resume  
2. NLP models extract keywords and skills  
3. Resume is compared with job requirements  
4. ATS score is calculated  
5. A full improvement report is displayed

---

## Tech Stack
- Python  
- Streamlit  
- Groq API  
- Advanced text processing
